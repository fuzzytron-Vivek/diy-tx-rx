# Transmitter and Receiver System
## Starting FAQ 
1. What is this ? 
   - This is a transmitter receiver model made from scratch , specifically meant for Radio Controlled Vehicles .
   - The brain of the system is composed of Arduino Nano clones and the communication modules are made up of NRF24L01 modules .
   - This project was inspired by a video made by a Youtuber named Electronoob , whose content greatly simplified the process of making the project .
2. Why was this made ?
   - This project was made as an initializer for me into embedded electronics and was mainly a reality check for my own competence .
   - This project was aimed at cutting the costs of buying an off the shelf transmitter receiver set , which was successfully met with this project being completed in one third of the price of a commerical TXRX set.
3. What does this repository contain ?
   - Transmitter firmware and hardware documentation  
   - Receiver firmware and signal handling logic  
   - Integration notes for a fixed-wing RC jet  
   - Debugging notes and testing observations
4. Did the aircraft fly?
    - The airframe was fully assembled and **functionally validated through ground and bench testing**.  
    - A brief flight attempt was conducted; however, **full flight testing and video documentation were intentionally limited** due to environmental and airspace safety considerations. 
    - This repository therefore emphasizes **system design and validation** over flight footage.
5. Most Challenging part of the project 
    - Ensuring **reliable communication and predictable actuator behavior** under real-world constraints such as noise, timing issues, and signal loss.
